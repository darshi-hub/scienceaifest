## 3. Chemical hallucinations: “impossible bonds” and non‑physical molecules

Problem: Purely generative models (diffusion, transformers, graph GANs) will sometimes propose structures that violate basic valence rules or thermodynamics—e.g., pentavalent carbon in a neutral organic environment, broken octet rules, insane ring strain, or conformations that collapse under real physics. [academic.oup](https://academic.oup.com/jlb/article/13/1/lsag014/8566432)

If you pass these through as “candidate molecules,” your credibility drops and you risk misleading non‑expert users.

Technical fix: Integrate **hard‑coded chemistry and physics filters** (RDKit, OpenMM, similar engines) into the generation pipeline so impossible or grossly implausible structures are auto‑rejected. [academic.oup](https://academic.oup.com/jlb/article/13/1/lsag014/8566432)

Typical stack for your use case:

- Cheminformatics validation (RDKit or similar):  
  - SMILES / graph parsing.  
  - Valence checks (no pentavalent neutral carbons, correct valence for N, P, S, etc.).  
  - Aromaticity detection and ring sanity.  
  - Substructure filters (automatically reject highly reactive or banned motifs, e.g., certain azides, unexploded peroxides).  
- Geometry and basic physics (OpenMM or similar):  
  - Build 3D conformer(s) from 2D graph.  
  - Quick energy minimization.  
  - Flag candidates with extreme strain or failure to converge.  
  - Coarse stability heuristics (e.g., predicted lifetime under ambient conditions).

Pipeline architecture (high‑level):

1. **User defines constraints** (e.g., “biodegradable polyester, dissolves in seawater in ≤ 12 months, minimal toxicity to marine life”).  
2. **Generative model proposes candidate graphs** (dozens to thousands).  
3. **RDKit validation filter**:  
   - Reject any candidate failing valence/aromaticity/basic chemistry checks.  
   - Annotate remaining molecules with computed descriptors (LogP, TPSA, molecular weight, etc.).  
4. **Physics / stability filter (OpenMM)**:  
   - Build 3D, run short minimizations; discard those that are clearly non‑physical or grossly unstable.  
5. **Property prediction models**:  
   - Use QSAR/QSPR or ML regression to estimate solubility, biodegradation rate proxies, mechanical properties.  
6. **Front‑end ranking and explanation**:  
   - Show only molecules that passed all chemistry/physics filters.  
   - Explicitly display which filters they passed and where predictions are uncertain.

UX affordances:

- “Physics Check” indicator on each candidate:  
  - Green: passed basic valence & minimization.  
  - Yellow: borderline or high uncertainty.  
  - Red: rejected or only shown in “sandbox” mode for advanced users.  
- Option for expert mode:  
  - Allow researchers to see rejected candidates with clear warning: “Failed chemistry validation (e.g., valence rule violation). Shown for diagnostic/academic purposes only.”

This not only improves scientific seriousness but also directly addresses hallucination risk and aligns your system with best practices in AI‑assisted sciences that embed domain constraints into the pipeline. [academic.oup](https://academic.oup.com/jlb/article/13/1/lsag014/8566432)
