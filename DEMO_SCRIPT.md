## What To Do If...

### ...Sliders Don't Work
**Refresh the page** (Ctrl+R or Cmd+R)
If still broken, **click the browser's reload button**

### ...Generation Takes Too Long
- It's using mock data (no API key set) - this should take 3 seconds
- If it takes longer than 10 seconds, **refresh and try again**
- Check internet connection

### ...The 3D Molecule Doesn't Appear
- This is normal! It shows an artistic SVG representation instead
- Say: "The AI proposes the molecular structure, here's our visualization"

### ...Browser Freezes
- Close the developer console (F12)
- Disable extensions (especially ad blockers)
- Use a different browser

### ...You Lose Internet Mid-Demo
- The mock data still works! Just continue the demo
- Explain: "For this demo, we're showing simulated results"

## Presentation Tips

✅ **Do:**
- Start with the hero animation (it's impressive!)
- Move slowly through the sections
- Adjust sliders deliberately, explain why
- Make eye contact, don't read slides
- Use your voice to build excitement
- Let the animations play (they're engaging)

❌ **Don't:**
- Rush through - 5 minutes is plenty of time
- Click too fast - let people absorb visuals
- Get technical (avoid chemistry jargon unless asked)
- Apologize for "just a demo" - it's professional!
- Spend time explaining code - focus on science
